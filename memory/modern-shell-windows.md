# Modern Shell, Rust/Wasm CLI & Global PATH Contract on Windows (Nov 2026)

- Never rely on legacy Windows PowerShell 5.1 (`powershell.exe`) syntax or quoting behavior. Prefer **Nushell** (`nu` v0.117+ at `%LOCALAPPDATA%\Programs\nu\bin\nu.exe`), **PowerShell 7.7+** (`pwsh`), or direct **Bun** (`bun -` stdin) for structured scripting and native process invocations.
- Installed core November 2026 Wasm/Rust/GPU CLIs: `nu` (`0.117.0`), `pwsh` (`7.7.0`), `mise` (`2026.11.2`), `wasmtime` (`50.0.2`), `wasm-opt` (`v133`), `wasm-bindgen` (`0.2.129` lockstep with `Cargo.lock`), `wasm-tools`, `wat2wasm`/`wasm2wat`, `wit-bindgen` (`0.63.0`), `wac` (`0.12.0`), `cargo-hakari` (`0.9.39`), `procs` (`0.14.12`), `choose` (`1.3.7`), `ast-grep`, `rg`, `fd`, `eza`, `bat`, `zoxide`, `starship`, `atuin`, `jj`, `hyperfine`, `xh`, `dxc`, `glslangValidator`, `spirv-val`.
- Keep `~/.bun/bin`, `~/.cargo/bin`, `~/.local/bin`, Nushell, and Wasmtime ahead of legacy shims (`Niubash`, `WindowsApps`, `RosBE`); audit/optimize anytime via `bun tooling/bun/shell-path-doctor.ts audit|optimize`.
- Non-interactive agent startup stays `<15ms`: gate `starship`/`zoxide` prompt initialization behind `if $nu.is-interactive` in `%APPDATA%\nushell\config.nu` and `$isInteractiveShell` in `Documents\PowerShell\Microsoft.PowerShell_profile.ps1`.
- PowerShell 5.1 pipelines (`|`) decode/re-encode stdout as text and corrupt binary streams (`tar cf - | ssh ...`); use `cmd /c` or base64 transport for binary pipes to remote hosts.
- For remote Linux bash commands from PowerShell 7, pipe a single-quoted here-string (`@' ... '@ | ssh <host> "tr -d '\r' | bash"`) instead of inline double-quoted scripts (prevents PowerShell `$VAR` expansion, quote breakage, and `\r` errors; never nest `@' ... '@` inside another `@' ... '@`).
- Never pass unexpanded `~/.gemini/...` paths to native executables (`bun`, `rg`) in PowerShell `run_command` (PowerShell leaves literal `~` in native args); always use `"$HOME/.gemini/..."`, which resolves identically in `pwsh`, `powershell`, `nu`, and `bash`.
- Global `~/.cargo/config.toml` sets nightly `-Zthreads=8 -Zshare-generics=y` on `x86_64-pc-windows-msvc`; in workspaces pinning a stable `rust-toolchain.toml`, set `CARGO_TARGET_X86_64_PC_WINDOWS_MSVC_RUSTFLAGS="-C target-cpu=native"` for lightweight local checks and run heavy builds on `fr1`.
