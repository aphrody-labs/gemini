# gemini

Portable global configuration of the Gemini CLI / Antigravity for the Aphrody estate. It holds `GEMINI.md`, the settings and MCP templates, the hooks, the extension enablement and `scripts/install.ts`; it holds no path of a machine, no junction, no cache, no history and no trust list.

Setup on a machine: clone to `~/.gemini`, run `bun scripts/install.ts`. The script renders `settings.json` and `config/mcp_config.json` from the templates and materializes `plugins/*` into `config/plugins/*` as real directories (the plugin source is `plugins/` here, with no `~/.claude` dependency). `plugins/cloudflare` is the unmodified official `cloudflare/skills` plugin (`agy plugin install <clone>`, then `gemini extensions link ~/.gemini/plugins/cloudflare`; only `gemini-extension.json` is added for the Gemini CLI); never vendor Cloudflare skills into `plugins/aphrody` (see `SUPERSEDED` in `scripts/vendor-skills.ts`). Machine- and work-specific files (trusted folders, projects, installation id, history, logs) belong to the private `gemini-local` repository or stay untracked.
